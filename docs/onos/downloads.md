# Downloads

ONOS packages are meant to be the official source for any production deployment. If you need to deploy ONOS in production, please download the *tar.gz* package using the links below or pull the [docker image](https://hub.docker.com/r/onosproject/onos/) for the desired ONOS release.

For development activities, you can pull the ONOS **source code** by [cloning the ONOS repository](guides/developer-guide/development-environment-setup/getting-the-onos-core-source-code-using-git-and-gerrit.md).
