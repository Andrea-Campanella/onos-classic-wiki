## Test Suite Naming Conventions:

The following test name convention should be followed for TestON tests - folder "*name*", "*name*.py", "*name*.params", "*name*.topo" and python class *name*.

Core Tests:

CHO\* - for longevity tests

HA\* - for high availability tests

FUNC\* - for individual functionality or features tests

SCPF\* - for performance and scale-out tests

Use Case Tests:

SDNIP\* - for testing SDNIP use case

SR\* - for testing Segment Routing use case

VPLS\* - for VPLS tests
