# The ONOS Project

The ONOS Project focuses on the development and support of the Open Network Operating System (ONOS) and its feature proposals and use cases. To elaborate:

* **ONOS** refers to the SDN platform and network operating system that is the primary focus of the ONOS project's development and support activities
* A **feature proposal** refers to work aimed at adding features to, or enhancing existing features of, ONOS itself
* A **use case** refers to a project that incorporates ONOS as an integral part of its functionality

This guide focuses on ONOS itself. Use cases have development cycles and contribution procedures independent of the ONOS project. While the procedures and tools used by a use case often overlap with those used for ONOS (and discussed here), those who are interested in working on a use case should refer to the [information provided by their use case of interest](../../apps-and-use-cases.md) for specifics.
