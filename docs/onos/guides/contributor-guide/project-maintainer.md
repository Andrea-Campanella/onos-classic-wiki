# Project Maintainer

## 

## What is a Project Maintainer?

A **"project maintainer"** is someone with the following project permissions:

* Administrative rights in Gerrit projects
* Create new branches and repos
* Push rights to repos, when necessary
* +2 Code Review / +1 Verification for entire project(s)

This role is somewhat orthogonal to the Module Owner track. It is targeted for community members that work on build and release processes, as well as cleanup, maintenance and reorganization efforts.

## Becoming a Project Maintainer

Candidates must have extensive experience with the project's source code and structure, and they serve as general custodians with great responsibility.

Nominations for new project maintainers must be made by a member of the TST. If you are interested in becoming a maintainer, please reach out to a member of the TST to discuss your nomination.
