# Topology Alternate Maps

# Overview

The topology view includes a "map" layer which can provide a geographic frame of reference for the visualized network topology. The default map is that of the Continental US.

This page provides details on how to render an alternate geographic region.

*(NOTE: This page is currently a WIP)*

The long term intention is that maps can be provided in one of two ways:

* Select one from a set of pre-loaded geographic regions
  + The list of regions will hopefully expand over time
* Roll your own custom region
