# GUI Topology 2 Overlay API

This page describes the JavaScript API that the Topology 2 View provides to allow contributed application code to integrate with, and provide additional functionality to, the topology view.

Note that this API pertains to the "Region-aware" Topology View (topo2). For the "Classic" Topology View, see [here](../gui-topology-view/gui-topology-overlay-api.md).

# Topology Overlay Service

The *Topology Overlay Service* is a JavaScript module that provides the [client-side API](https://github.com/opennetworkinglab/onos/blob/master/web/gui/src/main/webapp/app/view/topo2/topo2Overlay.js) for registering new "topology overlay" components.
