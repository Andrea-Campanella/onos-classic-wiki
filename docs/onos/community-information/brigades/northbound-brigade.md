**Scope:**

This brigade will be slightly staggered off the Deployment Brigade.

The purpose of this brigade is to incrementally expand the functionality of the existing Intent Framework. This includes feature enhancements and bug fixes. The scope of this brigade could be expanded to focus on making the intent framework work with specific devices and protocols.

* Short-term focus in 2017:
  + Enable bandwidth reservation via Intent Framework (Luca, Pier)
  + Implement a mechanism for bandwidth enforcement for framework's B/W reservations (Luca, Pier, Jordi, Alaitz)
  + Intent installer improvements (Yi, Andreas, Michele)
  + Resource service enhancements (Sho)
  + Let multiple intents share resources (Yi, Luca, Pier)
  + Let the intent framework work on OFDPA pipeline (Yi)
  + Support for groups on intent framework (Yi)
  + Create a new multipoint-to-multipoint intent that groups all existing (sp2sp, sp2mp, mp2sp) intents (Pier? Himal?)
