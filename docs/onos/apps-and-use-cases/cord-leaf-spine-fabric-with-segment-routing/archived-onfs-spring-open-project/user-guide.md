# User Guide

Welcome to the SPRING-OPEN User Guide. The 'Getting Started Tutorial' is a good place to .. umm ... get started.

Once you have gotten a touch and feel of things, and are ready to try your own network, or follow the built-in network example that is vividly demonstrated in the [Prototype videos](prototype-demo-videos.md), check out the 'Configuring ONOS' page below. To get your network up and running, you would need to make the choice of using software switches (in Mininet) or hardware switches (from Dell). Either way, you would need to follow the 'Configuring ... Switches' pages below. Finally the CLI for the controller can be used to monitor the network, as well as configure tunnels and policies. Checkout the 'Using the CLI' page for available CLI commands as well as the Prototype videos on how to enable the implemented Segment Routing features.
