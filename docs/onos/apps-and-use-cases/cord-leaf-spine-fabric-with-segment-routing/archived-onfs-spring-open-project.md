# [Archived] ONF's SPRING-OPEN project

## Welcome to the Open Networking Foundation's  **SPRING-OPEN** project.

This use-case was developed on an older dev-branch of ONOS before the official Avocet release of ONOS in Dec 2014. A significant part of this work has been ported to the official ONOS code base under the "segment routing" application, and mainly used today to support a leaf-spine datacenter fabric (in the Atrium and CORD projects).

If you are interested in trying out this earlier work, please use the guides below.
