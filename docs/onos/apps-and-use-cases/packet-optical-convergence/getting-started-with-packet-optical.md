# Getting Started with Packet Optical

There are several pages for getting started with this use case. This is also a good place to begin for [E-CORD](../cord-central-office-re-architected-as-a-datacenter/e-cord-enterprise-cord.md), which builds on the Converged Packet Optical use case.

* The [Packet Optical Tutorial](getting-started-with-packet-optical/packet-optical-tutorial.md) is recommended for those who wish to get a feel for the features implemented for this use case, without the work of setting the environment up from scratch.
* The [Packet Optical Dev Environment](getting-started-with-packet-optical/the-packet-optical-dev-environment.md) is recommended for developers, and those interested in building an environment similar to the one used by the developers working on this use case.
* The [E-CORD Developer Environment](../cord-central-office-re-architected-as-a-datacenter/e-cord-enterprise-cord/e-cord-developer-environment.md) is a good next step for those interested in developing/testing for E-CORD, and the emulation of multi-domain networks.
