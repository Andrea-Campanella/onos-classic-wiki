# ONOS Documentation

## Overview

This page contains information related to the work done by the (unofficial) ONOS documentation group. This page is intentionally separate from contributor information since it's more closely in line with a working group landing page (but the landing page for the docs is, and should be, [ONOS](index.md)).

## Meetings

This group holds community calls to discuss various aspects of ONOS documentation (currently the wiki) and related resources, for those interested in, or are, contributing to documentation for the ONOS platform.

Agenda items and notes are collaboratively added [here](https://docs.google.com/document/d/1VyQMjvfTGmDTA10IlB0A-QP8ACPnOlGC4WYoiFRkH9Q/edit?usp=sharing). Notes are later distilled into minutes, which are linked in the table below.
